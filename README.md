# Навыки (skill-dashboard)

Локальное Electron-приложение: читает заметки Obsidian с навыками фронтенда, показывает прогресс по ним и пишет уровни обратно. Личный инструмент, чтобы свериться, где ты по темам, и спокойно поправить оценки.

## Что делает

- Собирает из базы знаний Obsidian (`10-knowledge/<домен>/*.md`) дерево: домен, тема, под-навык, шкала 0-10.
- Даёт поправить уровень навыка прямо в приложении; запись идёт обратно во frontmatter заметки.
- Подсвечивает слабые места: самые низкие навыки по всему дереву.
- Следит за базой знаний: правки в Obsidian подхватываются без перезапуска.
- Каталог рекомендованных курсов под темами и общими областями фронтенда, с трекингом прохождения (чеклист вех или статус).

## Стек

- Electron, electron-vite
- React 19, TypeScript
- Vite
- gray-matter (frontmatter), chokidar (слежение за файлами)
- vitest (тесты)

## Как устроено

Источник правды - vault в Obsidian. Приложение хранит путь к нему в `userData`, читает `.md` через gray-matter и рисует дерево. Правка уровня переписывает только блок `skills` во frontmatter, тело заметки остаётся как есть. Слежение (chokidar) перечитывает дерево при внешних изменениях, причём собственные записи не вызывают эхо.

Прогресс по курсам лежит в `_courses-progress.md` в корне базы знаний, в обычном markdown с галочками, так что его видно и можно править прямо в Obsidian.

## Запуск

```bash
npm install
npm run dev        # запуск в режиме разработки
npm run dist       # сборка .app (в release/)
npm test           # тесты
npm run typecheck  # проверка типов (node + web)
```

При первом запуске приложение попросит выбрать папку базы знаний.

## Структура

```
src/
  main/         процесс Electron: IPC, чтение и запись vault, слежение за файлами
    vault/      парсер заметок, writer уровней, прогресс курсов
  preload/      мост window.api (contextBridge)
  renderer/     интерфейс на React
  shared/       общие типы, каталог курсов, деривации
```

## Формат заметки

Уровни под-навыков хранятся во frontmatter заметки:

```yaml
---
title: Замыкания
status: solid
skills:
  - name: closures
    level: 6
  - name: scope chain
    level: 7
---
```

Остальной frontmatter и тело заметки приложение не трогает.

## Тесты

Логика (парсер, writer, деривации, прогресс курсов) покрыта vitest. Запуск: `npm test`.
